# Code Alpha Repository
 This repository contains the internship projects developed as part of my internship in Code Alpha. It includes two main tasks showcasing fundamental programming skills and practical applications.

 ---

## 📸 Task 1: Image Gallery

1.Design an image gallery using HTML and CSS layout.<br>
2.Use JavaScript for navigation (next/prev buttons, lightbox view).<br>
3.Add hover effects and smooth transitions.<br>
4.Ensure responsive design for different screen sizes.<br>
5.Bonous: Add image filter or categories.<br>

---

## 📸TASK 2: Build a Calculator

1.Create a basic calculator using HTML, CSS, and JavaScript.<br>
2.Include all arithmetic operations: +, -, x, .<br>
3.Design a user interface with buttons and display screen.<br>
4.Handle user input, clearing screen, and real-time result display.<br>
5.Bonus: Add keyboard support and styling enhancements.<br>

---
